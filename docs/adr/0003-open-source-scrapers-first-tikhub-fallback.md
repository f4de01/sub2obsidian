# 采集先用本地开源工具，TikHub 作为备选

B站与抖音的采集首选本地运行的开源工具（yt-dlp、F2），用用户自己的登录 cookie、低速请求：免费，且 cookie 与收藏记录不经过第三方。这些工具受平台风控与律师函影响而脆弱（BBDown、bilibili-api 已在 2026 年归档），所以每个平台适配器都必须可替换；若实际使用中抓取持续失败，优先评估付费第三方数据 API TikHub 作为该平台适配器的替代实现，而不是自行逆向签名。

## Consequences

- 切换到 TikHub 意味着付费、依赖外部服务，且来源链接（以及可能的账号凭据）会发给第三方；切换前需重新评估这一点。
- 适配器的边界要按"给定平台账号/链接 → 产出来源的元数据与原始材料"来设计，与具体抓取实现无关。
